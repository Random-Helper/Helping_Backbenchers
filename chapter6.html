Chapter - The Data Science Squad

Introduction to Data

Data: Raw facts, numbers, information, or instructions that can be stored and processed by a computer.

Computers store data in binary form, using only 0 and 1.

Forms of Data

  • Text: Written information such as books, websites, articles, and newspapers.
  • Audio: Sound information such as songs, speeches, and news.
  • Image: Visual information such as pictures and scanned documents.
  • Video: Moving visual information such as movies, clips, and online lectures.

Types of Data

Data is mainly divided into quantitative and qualitative data.

Quantitative Data

Quantitative data: Data that can be represented using numbers and can be counted or measured.

It answers: How many? How much? How often?

Examples: Age, year, temperature, weight, height, and salary.

Qualitative Data

Qualitative data: Data that describes qualities or characteristics.

It answers: Why? What? How?

Examples: Behaviour, quality, reviews, appearance, and descriptions.

Quantitative vs Qualitative Data

  • Quantitative: Represented using numbers.
  • Qualitative: Represented using words or text.
  • Quantitative: Collected through measurements or formulas.
  • Qualitative: Usually collected through observations.

Types of Quantitative Data

Continuous Data

Continuous data: Numerical data that can have any value within a range.

It can take many possible values, including decimal values.

Examples: Temperature, weight, salary, and height.

Discrete Data

Discrete data: Numerical data that has fixed and countable values.

It is generally measured using whole numbers.

Examples: Number of students, siblings, printers, employees, or balls.

Continuous vs Discrete Data

  • Continuous: Can have many possible values between two numbers.
  • Discrete: Has fixed, countable values.
  • Continuous: Can include decimal values.
  • Discrete: Usually uses whole numbers.

Use of Data in Recommendations

Platforms analyse your search history, current searches, and choices to recommend videos, products, or other content that may interest you.

Examples:

  • Video recommendations
  • Friend suggestions on social media
  • Flight suggestions on booking platforms
  • Product recommendations
  • Analysing customer demand

What is Data Science?

Data Science: A field that uses data, tools, algorithms, statistics, and technology to find useful information and make informed decisions.

Data science involves collecting, preparing, analysing, and presenting data to find useful patterns and insights.

Life Cycle of Data Science

1. Capture

Capture: Collecting raw data from reliable sources.

Data can be collected in the form of text, numbers, images, and videos.

2. Maintain

Maintain: Storing, cleaning, organising, and managing data so that it can be used properly.

Data may be stored in structured or unstructured formats.

3. Process

Process: Preparing data by finding patterns, ranges, and distributions so that computers can analyse it.

4. Analyse

Analyse: Studying prepared data to find useful information and insights.

Methods such as statistical analysis, predictive analysis, regression, machine learning, and deep learning may be used.

5. Communicate

Communicate: Presenting the results of data analysis using graphs, reports, and other visualisations.

Applications of Data Science

Banking

Data science helps banks detect fraud, recommend loans, track data, and understand customers.

Healthcare

Data science helps doctors examine patients, detect diseases early, classify diseases, and monitor patients' conditions.

E-Commerce

Data science helps online stores recommend products based on a user's browsing and purchasing history.

Transport

Data science is used in self-driving cars and GPS systems to make decisions based on traffic and location data.
