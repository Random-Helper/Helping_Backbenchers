String Operators

String basically means words/letter it can include number but they will also be treated as characters/letters, integer means a whole number but it dosent include decimals just numbers, decimals are included in float along with numbers.

String operators are used to perform operations on strings.The concatination(+) operator is used to join strings, while the Replication(*) operator is used to repeat a string multiple times.

 a = "Hello " b = "World" print(a + b) print("Hi " * 3)

The first one results to HelloWorld while the second one results to HiHiHi

Assignment Operators

Assignment operators are used to assign values to variables.Other assignment operators combine an arithmetic operation with assignment.

  • = — Assigns a value to a variable.
  • += — Adds a value and assigns the result.
  • -= — Subtracts a value and assigns the result.
  • *= — Multiplies a value and assigns the result.
  • /= — Divides a value and assigns the result.

Relational Operators

Relational operators are used to compare two values. The result of a relational operation is either True or False.

  • < — Less than
  • > — Greater than
  • <= — Less than or equal to
  • >= — Greater than or equal to
  • != — Not equal to
  • == — Equal to

Logical and Boolean Operators

Logical operators are used to combine or modify conditions. Python has three logical operators: and, or, and not. They work with Boolean values, which are True or False.

  • and — Returns True when both conditions are True.
  • or — Returns True when at least one condition is True.
  • not — If the condition is true it shows false, and if false it shows true.

Control Statements

As the name suggests Control statements are used to control the flow of execution of a Python program. They allow a program to make decisions based on conditions.

if Statement

The if statement executes a block of code only when the given condition is True.

age = 18

if age >= 18:
    print("Eligible")

if-else Statement

The if-else statement provides two choices. The if block is executed when the condition is True, otherwise the else block is executed.

age = 18

if age >= 18:
    print("Eligible")
else:
    print("Not Eligible")

if-elif-else Statement

The if-elif-else statement is used when there are multiple conditions. Python checks the conditions one by one and executes the block belonging to the first condition that is True. If none of the conditions are True, the else block is executed.

 marks = 75 if marks >= 90:
   print("Topper") 
elif marks >= 60:
   print("Average") 
else: 
   print("Study")

Loops

Hardest topic in my opinion

Loops are used to repeat a set of statements multiple times. Python provides for and while loops for performing iteration.

For Loop

A for loop is used to repeat a block of statements for each value in a sequence. It is commonly used with the range() function.

The range function gives a range of number to use, typically in a for loop. It does not include the last number.

for i in range(1, 6):
    print(i)

This will print the numbers 1 to 5 and will exclude 6.

While Loop

A while loop repeatedly executes a block of statements as long as the given condition is True.

i = 1

while i <= 5:
    print(i)
    i += 1

This will print the numbers starting from one adding 1 after each time and will stop when the condition becomes false, in this case at 5.
